## 这份报告能证明什么、不能证明什么

- 能证明：我们**声明的** UA / UA-CH / 语言 / 时区 / 屏幕 / 硬件 / WebGL vendor+renderer / 媒体设备数量，和**页面里真实读到的**一致；四个噪声维度**同页稳定、跨重启稳定**；WebRTC 的 UDP 策略真的生效。
