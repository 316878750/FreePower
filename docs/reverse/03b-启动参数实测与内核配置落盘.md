## 1. 一句话总览

`browser/start` 打出的是 **一个定制 Chromium 进程**，指纹**不走命令行、不走 CDP、不走扩展**，而是四路喂给内核：

```
                    ┌─ 命令行参数  ──→ 只放 window/proxy/lang/UA 这类"看得见"的东西
browser/start ──────┤
                    ├─ sunBrowserParams (KV) ──► 启动器透传，内核当环境配置读
                    ├─ StaticConfig  (落盘)  ──► md5(profileId+"_static")，自定义 base64
                    └─ DynamicConfig (落盘)  ──► md5(profileId+"_webrtc")，自定义 base64
```

内核再由 `UserId`（= `browser_head`，即环境标题栏文字）去把自己的配置认领回来。

## 3. 命令行参数【码】

### 3.1 每次必带的基线（`--` 前缀，@135）

```
--protected-disable-safe-open
--remote-debugging-port=0
```

只有两条。`no_args="1"` 时**整个 args 数组被替换成这两条**；`cover_args` 非空时 = 这两条 + `cover_args`（@136-137）。

`--remote-debugging-port=0` 意味着**端口是内核随机挑的**，外部靠读 `DevToolsActivePort` 文件拿端口，而不是传固定端口。这是和普通 CDP 自动化最大的不同。

## 4. `browser/start` 响应形状【码】

`formatOpenRes()`（@791759）：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "ws": {
      "puppeteer": "ws://127.0.0.1:<port>/devtools/browser/<uuid>",
      "selenium":  "127.0.0.1:<port>"
    },
    "debug_port": "<port>",
    "webdriver": "<chromedriver 路径>",
    "marionette_port": "<firefox 才有>"
  }
}
```

细节：
- `ws.selenium` **只是 `host:port`，不是 URL**，也不能直接连 WebDriver——它是给 selenium 4 的 `debuggerAddress` 用的。
- `debug_port` 从 `selenium` 里按 `:` 切出来。
- `type=rpa`（内部 RPA 调用）时，额外返回 `userName` / `password` / `cookies` / `comment` / `browserName`（@791759）。
- `webdriver` 走 `getWebDriver(browserType, version)` 找 `chromedriver`；内核 92 或设了 `CHROME_DRIVER_PATH` 时直接用环境变量。
- 端口来源就是 `<user-data-dir>\DevToolsActivePort` 的第 1 行（本机实例该文件 60 字节，存在）。

## 5. 内核怎么拿到 StaticConfig / DynamicConfig

写入【码】@396-430：
1. `JSON.stringify(dynamicConfig)` → 非 `{}` 才写；路径 `md5(fbccId+"_webrtc")`，内容 = `encodeBase64(json)`。
2. `JSON.stringify(staticConfig)` → 同上，路径 `md5(fbccId+"_static")`。
3. **写入前做内容去重**：读旧文件、算 md5、和新内容 md5 比对，相同就不重写（减少磁盘写）。
4. 路径本身作为 `SB.DynamicConfig` / `SB.StaticConfig` 递交给内核。

`sunBrowserParams` 与 `staticConfig` 的关系（@408）：

```js
for (key in sunBrowserParams)
  if (key NOT IN ["CustomIcon","WebGLFP","StaticConfig","CookiesFile","DynamicConfig","Geoposition","TimeZone"])
      staticConfig[key] = sunBrowserParams[key];
```

→ **`sunBrowserParams` 里除这 7 个例外，全部会被复制进 `StaticConfig` 一起落盘**。这解释了为什么真实 StaticConfig 里会出现 `UserId`/`CanvasMark`/`AudioFp`/`Langs`/`Platform` 这些本该是「参数」的键。

## 6. 真实落盘内容【实】（`p5demo2_a1b2c3`，已脱敏）

### 6.1 「加密」其实是换表 base64

`encodeBase64(str, std, alt)`（@1065902）把标准 base64 的每个字符按索引映射到**另一张 64 字符表**：

```
STD = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/"
ALT = "hTy1bfRJz4nLPcBCO7WtmNIaGvVeul5Zo8kq32UxrYw_-0gsjp96SDFXQiEMKdHA"
```

映射规则：`out[i] = ALT[STD.indexOf(c)]`，找不到的字符原样保留。
**这不是加密，是可逆编码**，30 行代码就能解开（脚本见 `tools/decrypt-cfg.js`）。同一个 ALT 还用来编码 `login_cookie`、代理密码（`ipservice` 类型）。

### 6.2 DynamicConfig（`md5(profileId+"_webrtc")`，真实 355 B / 5 个键）

```json
{
  "StrongBlockList": { "Version": "3", "Domains": ["logcollection.info"] },
  "BlockList":       { "Version": "1676277424",
                       "Domains": ["memberprod.alipay.com","cnki.net","edu.cn","gov.cn",
                                   "tieba.baidu.com","wx.qq.com","..."] },
  "WebRTCAddress": "203.0.113.10",
  "TimeZone": "Asia/Hong_Kong",
  "Geoposition": "22.362543,114.119156,1000"
}
```

→ `Geoposition` 就是 `latitude,longitude,accuracy` 三段逗号串，和代码 `[lat,lng,acc].join(",")` 完全对上。
→ `BlockList` 是**国内站点黑名单 + 版本号**，远端下发，跟指纹无关，但会改变浏览行为。

## 7. 给 FreePower 的落地建议

我们没有 SunBrowser 那种定制内核，**这四路通道要重新设计**：

| AdsPower 做法 | FreePower 可行做法 | 注意 |
|---|---|---|
| `--user-agent=` | 同样用命令行 | 唯一能 1:1 照抄的 |
| `--remote-debugging-port=0` + `DevToolsActivePort` | 同样照抄 | 别用固定端口，多环境会撞 |
| StaticConfig 落盘给内核读 | **改走 CDP `Page.addScriptToEvaluateOnNewDocument`** | FreePower 已经在做，继续 |
| sunBrowserParams KV | 无对等物，合并进注入脚本的配置对象 | |
| ProxyChain（内核原生多级代理） | **做不到**，只能链式本地代理 | 这是能力差距，要写进 README |
| `TZ` / `LANGUAGE` 环境变量 | 照抄 | 成本最低、效果最好 |
| Canvas/Audio/WebGL 噪声在内核层 | CDP 注入改 `getImageData`/`OffscreenAudio`/`getParameter` | 比内核方案**更容易被检测**，必须如实告知 |

**必须照抄的三条基线参数**（FreePower 也该带，不然脚本跑起来行为不一致）：
`--protected-disable-safe-open`、`--remote-debugging-port=0`，以及把
`--disable-backgrounding-occluded-windows --disable-background-timer-throttling --disable-renderer-backgrounding`
放进 `ignoreDefaultArgs`（不是删掉，是让 puppeteer 不要覆盖）。

**Local API 端口**：CEO 定的 53380 起，与 AdsPower 的 50325 不冲突，正确。
**注意**：`ws.selenium` 是 `host:port` 不是 URL，FreePower 的 `/browser/start` 必须返回同样形状，否则现有脚本要改。
